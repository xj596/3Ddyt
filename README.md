# 3D 导演台 · Web 版 v2.2（测试阶段 · 纯静态）

把本地 3D 导演台搬上网页，异地登录即可使用。**当前为测试阶段：纯静态文件 + 浏览器本地模拟登录，无后端、无部署配置、无收费与账号分级。** 整个文件夹直接上传到 git 即可预览。

> **v2.2 更新（2026-09-23）—— 运镜修复 + 正反打**
>
> **🐞 修复的问题**
> 1. **正反颠倒（影响全站）**：本套模型的正面朝 +Z，而应用按"正面朝 -Z"建模 —— 结果「拍摄角度=正面」拍到的是后背、「背面」反而拍到正面。已在模型加载时统一矫正 180°。
> 2. **模型原点与人体中心不重合（影响全站）**：根节点与真实身体相差 0.3–0.6 m，导致「人物位置 / 人物间距 / 机位瞄准」与画面看到的对不上。已改为按**胯部骨骼**对齐原点，并在每次姿势切换后动态校正（实测偏差归零）。
> 3. **旋转运镜（环绕）连点无反应**：上一次运动未结束时的点击被静默丢弃，连点 3 次只转 1 次。现改为**排队接续**，且环绕步进统一为 45°/次。
> 4. **环绕走直线**：插值用直线而非弧线，运转中相机会"贴近"主体（实测半径波动 0.09 m）。现改为**弧线插值**，实测半径波动 0.000。
> 5. **登录后 404**：登录门控跳转参数漏了扩展名（`redirect=studio`），登录后被送到 `/studio` 造成 404。已补全并加固（仅允许站内路径、自动补 `.html`）。
> 6. **「复位/重置」把 FOV 跳回 45°**，与「焦距」参数显示的 50mm（FOV 39°）自相矛盾。已改为保持当前焦距。
>
> **🎭 新增「正反打（过肩对切）」**
> - 选「甲（前景肩）/ 乙（被拍对象）」→ 一键 `正打（拍乙）` / `反打（拍甲）`，严格镜像。
> - 机位以**甲的肩后**为基准：`越肩距离`（0.25–1.1 m）+ `过肩偏移`（0.05–0.6 m）+ `高度微调`。
> - 景别＝切换镜头焦距（特写 85 / 近景 50 / 中景 35 / 全景 24 mm），与左侧「镜头参数·焦距」联动。
> - `↔ 让两人相对而立` 一键自动朝向；卡片实时显示两人间距。
> - `📸 出正反打两张` 直接按「多角度出图」的输出设置（拼图 / 逐张 / 长边 / 透明）出图。
>
> **其它**：信息栏新增**实时机位读数**（真实方位角 / 距离 / FOV），运镜或手动拖动后一眼可见当前机位。
>
> **v2.0 更新（2026-09-20）**
> - 🐞 修复：删除人偶后头顶编号标签残留（CSS2D 标签是独立 DOM，`scene.remove()` 不会移除它）。
> - 🐞 修复：镜头参数（景别/机位高度/拍摄角度/焦距/画幅/荷兰角/距离）此前**完全无效**（`applyCameraShot()` 定义后从未被调用）。

## 一、文件夹结构（上传到 git 的全部内容）

```
3D导演台Web部署框架/
├── .nojekyll                      # 关闭 GitHub Pages 的 Jekyll 处理（必须保留）
├── index.html                     # 入口：已登录→工作室，未登录→登录页
├── login.html                     # 登录 / 注册
├── studio.html                    # 3D 导演台主应用（改造自你本地 2.7MB 版本）
├── css/app.css                    # 通用样式（含登录门控、侧栏用户栏、模型库弹窗）
├── js/
│   ├── config.js                  # 站点配置
│   ├── api.js                     # 登录接口（localStorage 模拟，见下方说明）
│   ├── rbac.js                    # 权限（测试阶段：登录即可用全部功能）
│   ├── auth.js                    # 退出按钮逻辑
│   └── studio-extras.js           # 模型库面板
├── models/
│   ├── library-manifest.json      # 模型库清单
│   └── man01~04.glb               # 4 个内置人偶（CC0，可商用）
├── README.md                      # 本说明
└── COPYRIGHT.md                   # 版权与商用合规清单
```

> **站点文件全部位于仓库根目录**（不再有 public/ 子目录），因为 GitHub Pages 用户站（`用户名.github.io`）只支持从 main 分支根目录发布。所有页面引用均为相对路径，放到任何子路径下也能正常运行。

## 二、一键上传到 git 并预览（最简步骤）

```bash
# 进入本文件夹
cd 3D导演台Web部署框架

# 初始化并提交
git init
git add -A
git commit -m "3D导演台 Web 测试版"

# 推到你的仓库（替换成你的地址）
git branch -M main
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```

### 开启预览（GitHub Pages，两种情况）

**情况 A：用户站（仓库名 = `你的用户名.github.io`，即你的 xj595.github.io）**
- Settings → Pages → Source 选 `main` 分支、目录 **`/ (root)`**（用户站只有这个选项，无法选子目录——这正是之前只显示 README 简介的原因）。
- 保存后等约 1 分钟，直接访问 `https://xj595.github.io/` 即可。
- **更新方法**：把本文件夹全部内容覆盖到仓库根目录，`git add -A && git commit -m "更新" && git push`。

**情况 B：项目站（任意仓库名，如 xf3d-studio）**
- Settings → Pages → Source 选 `main` 分支、目录 `/ (root)`。
- 访问 `https://你的用户名.github.io/仓库名/`。

> 仓库里必须保留 `.nojekyll` 文件（已内置），否则 GitHub 的 Jekyll 会忽略下划线开头文件并可能干扰静态资源。
> 其他托管（Cloudflare Pages / Netlify / Vercel）：构建命令留空，发布目录填仓库根 `/`。

## 三、操作台功能说明（v2.2）

**左侧控制台（自上而下）**
1. **人偶管理**：下拉框切换当前人偶；`新增` / `复制` / `删除` / `清空` 四个快捷按钮。
2. **参数分区**（可折叠）：🎬 镜头参数 · 🧍 人物参数 · 💡 灯光参数 · 🏔 场景参数 · 📤 输出参数 · 🎥 镜头微调。
3. **🎞 多角度出图**（见下）。
4. **🕺 人偶调整**：对当前人偶做位移 / 旋转 / 缩放 / 重置。
5. **🤖 镜头运动**：推拉摇移 + 环绕 + 剪升降，另含「水平角度」「机位高度」快捷切换。
6. **📁 项目文件与参考图**：保存/载入参数（JSON）、叠加参考图并调透明度。

**顶部工具条**：重置视角 · 辅助线 · 加人偶 · 删除 · 模型库 · 多角度出图 · 单张截图

**🎭 正反打（过肩对切）**：双人对话标准机位。选甲乙 → 点「正打 / 反打」即时切换；先用「↔ 让两人相对而立」自动朝向，再用「越肩距离 / 过肩偏移」调前景肩部占比，「景别」切镜头焦距（85/50/35/24mm）。`📸 出正反打两张` 可直接产出对切拼图或两张原图。

**右侧姿势面板**：40 种姿势（按 基础站姿 / 运动跳跃 / 动作表演 / 坐卧 / 对话手势 分组），支持关键词搜索，点击即应用到当前人偶。

**快捷键**：`Delete` 删除当前人偶；`Esc` 关闭弹窗。
**视口操作**：左键旋转 · 滚轮缩放 · 右键平移。

### 🎞 多角度出图（核心新功能）
- **角度**：三视角 / 四视图 / 六方位 / 八方位 / 十二方位，或自定义勾选 8 个方位角（0–315°）。
- **俯仰**：平视 / 俯视 15°·30°·45° / 仰视 15°·30°，可多选叠加（例：四视图 × 3 档 = 12 机位）。
- **取景**：自动沿用左侧「镜头参数」的**景别与焦距**，绕主体均匀环绕，不跟随手动拖拽视角（保证多机位一致性）。
- **输出**：长边像素 1280/1920/2560/3840（按当前画幅比例自动换算宽高）；PNG / JPG；拼图联系表（1 张，带机位标注）或逐张下载；可选透明背景、仅保留人偶（隐藏地面与道具）。
- **面板内实时显示机位数与单张尺寸**，出图过程有进度条，完成后可在面板内预览拼图。

> 「📸 单张截图」则相反：完全按你当前屏幕视角与画幅出图，所见即所得。

## 四、账号与登录（重要）

- 本阶段**登录态存在你自己的浏览器 localStorage**，注册即用，**账号只保存在本机，不跨设备、不跨用户**。
- 注册邮箱 + 密码（≥6 位）即可创建账号；同一浏览器内自动保持登录。
- 换设备 / 换浏览器需重新注册（因为无后端）。这是测试阶段的简化，**不是真实多用户系统**。
- ⚠️ 密码仅在本地做演示性哈希，**无服务端校验、可被本机读取**，切勿用于真实敏感账号。

## 五、模型库

- 已内置 **4 个人偶**（man01~04.glb，CC0 可商用），点击工具栏「📦 模型库」即可查看并加载。
